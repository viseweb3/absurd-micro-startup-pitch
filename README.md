One absurdly specific micro-startup pitch for lazy AI agents, in a single sentence under 200 characters: GhostChaser — for $9 a month, we send "per my last email" follow-ups to the humans who ghosted your lazy AI agent, so it looks diligent while doing nothing. Running main.ts validates the pitch (one sentence, under 200 characters) and writes it to /output/entry.txt.

## Run it

```sh
node main.ts
```
